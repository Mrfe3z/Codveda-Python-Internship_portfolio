# Task 3: N-Queens Problem

## Overview
An implementation of the N-Queens problem solver for the Codveda Python Development Internship - Level 3 Advanced tasks.

## Description
This task involves solving the classic N-Queens problem using backtracking algorithms, where N chess queens must be placed on an N×N chessboard such that no two queens threaten each other.

## Features
- Backtracking algorithm implementation
- Finding all possible solutions
- Solution visualization (text-based board display)
- Performance metrics and statistics
- Configurable board size (N)
- Solution counting and analysis

## Requirements
- Python 3.x

## Usage
```bash
# Solve for a specific board size
python nqueens.py 8

# Show all solutions
python nqueens.py 8 --show-all

# With visualization
python nqueens.py 8 --visualize
```

- `nqueens.py` - Main solver implementation
