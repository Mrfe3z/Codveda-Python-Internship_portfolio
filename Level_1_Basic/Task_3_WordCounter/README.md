# Task 3: Word Counter

## Overview
A word counting utility implementation for the Codveda Python Development Internship - Level 1 Basic tasks.

## Description
This task involves creating a program that analyzes text and provides word frequency statistics and other text-based metrics.

## Features
- Count total words in text
- Count unique words
- Word frequency analysis
- Character count statistics
- Sentence count
- Support for file input and/or direct text input

## Requirements
- Python 3.x

## Usage
```bash
python word_counter.py
```

Or with a file:
```bash
python word_counter.py filename.txt
```

## Structure
- `word_counter.py` - Main word counter implementation

## Learning Objectives
- Work with strings and text processing
- Use dictionaries for frequency counting
- Implement file I/O operations
- Practice data analysis and statistics
- Build useful utility functions
