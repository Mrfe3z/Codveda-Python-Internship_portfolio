# Level 1 - Fundamentals

Entry-level projects focusing on core Python concepts.

## Projects

### Task 1: Calculator
- Concepts: Functions, loops, conditional logic, error handling
- Skills: User input validation, exception handling
- Run: `python calc.py`

### Task 2: Number Guesser  
- Concepts: Random generation, loops, conditionals
- Skills: Game logic, user feedback
- Run: `python num_guesser.py`

### Task 3: Word Counter
- Concepts: File I/O, string manipulation
- Skills: Reading files, data analysis
- Run: `python word_counter.py`
