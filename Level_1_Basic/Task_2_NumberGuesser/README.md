# Task 2: Number Guesser

## Overview
A number guessing game implementation for the Codveda Python Development Internship - Level 1 Basic tasks.

## Description
This task involves creating an interactive game where the user tries to guess a randomly generated number within a specified range.

## Features
- Random number generation
- User input and feedback mechanism
- Hint system (e.g., "too high" or "too low")
- Attempt counter
- Replay functionality

## Requirements
- Python 3.x

## Usage
```bash
python number_guesser.py
```

## Structure
- `number_guesser.py` - Main game implementation

## Learning Objectives
- Work with random number generation
- Implement loops for game flow
- Practice conditional statements
- Build interactive user input/output handling
- Understand game logic and flow control
